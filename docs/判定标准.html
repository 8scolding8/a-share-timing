要点

  1. 按原文，67% 的交易日不属于任何状态。 原文每个状态的条件要全部同时满足，覆盖面很窄。出现很少的状态：过热冲顶 6 天、恐慌出清 0 天。
  2. 合理性检查 2/5 符合。不符的：2020-02-03 疫情冲击 判为未满足任何状态；2025-04-07 关税冲击 判为未满足任何状态；2024-10-31 9·24 之后 判为未满足任何状态。具体哪些条件没满足见第六节。
  3. 瓶颈条件见第二节：每个状态“去掉某一条后能多出多少天”，帮助判断是哪条口径过严。
  4. 状态标签描述“现在是什么市场”和风险高低，不是买卖信号；看板不出仓位。
  5. v1 规则的对照见《判定标准修改建议》：v1 最新判定为 恐慌出清，原文最新判定为 熊市主跌。
