# A股择时看板

在线查看：https://8scolding8.github.io/a-share-timing/

- 页签：总览、市场状态（六状态逐条条件与证据）、四指数（沪深300、中证1000、创业板指、科创50）、指标（约 110 个指标的分位与历史证据，可下钻）、超跌反弹、数据（审计与数据质量）。
- 支持按日回放：回放到某一天，只用那一天能拿到的数据和统计。
- 数据截至 2026-11-23，来自公开渠道。
- 页面不引用任何外部地址；脚本不能运行时会显示当天的静态图表。
- 离线版：`offline.html`（单文件约 10 MB，下载后用浏览器直接打开，不需要联网）；网页顶部也有“下载离线版”链接。

仅供内部研究讨论，不构成投资建议。
